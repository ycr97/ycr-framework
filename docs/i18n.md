# 国际化（i18n）

`ycr-starter-i18n` 提供按请求头切换语言的 `LocaleResolver` 与静态取词工具 `I18nUtils`。

## 依赖

```xml
<dependency>
    <groupId>com.ycr.framework</groupId>
    <artifactId>ycr-starter-i18n</artifactId>
</dependency>
```

## 配置

前缀 `ycr.i18n`：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `ycr.i18n.enabled` | `true` | 是否启用 |
| `ycr.i18n.default-locale` | `zh_CN` | 默认语言（无 `X-Lang` 头时） |

消息文件仍走 Spring 标准 `spring.messages.basename`（如 `messages`、`messages_en` 放 `src/main/resources`）。

## 语言切换

`HeaderLocaleResolver` 按请求头 `X-Lang` 解析语言（如 `X-Lang: en`、`X-Lang: zh-CN`）；缺省用 `default-locale`。

```
GET /api/xxx
X-Lang: en
```

## I18nUtils

按当前请求语言取词：

```java
String msg = I18nUtils.getMessage("user.not.found");
String msg2 = I18nUtils.getMessage("greeting", "Alice");          // 带占位参数
String en  = I18nUtils.getMessage("user.not.found", Locale.ENGLISH);
```

`messages.properties`：

```properties
user.not.found=用户不存在
greeting=你好，{0}
```

`messages_en.properties`：

```properties
user.not.found=User not found
greeting=Hello, {0}
```
